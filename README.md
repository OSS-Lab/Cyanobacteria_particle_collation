# Cyanobacteria_particle_collation
This repository contains materials relating to:

Poon et. al. "Emergent particle collection by cyanobacteria through gliding motility and filament buckling", eLife15:RP112517
https://elifesciences.org/reviewed-preprints/112517

Please browse the folders above for the 3D biophysical model of cyanobacterial gliding motility, image analysis code, and the phylogenetic analysis, described in the above paper.

Associated timelapse videos for individual figures of the paper, as well as supplementary videos, are available at: 

https://zenodo.org/uploads/18680430
